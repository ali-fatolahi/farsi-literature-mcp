# Community contributions

This directory accepts structured community submissions in three categories:

- `ideas/` — use cases, conceptual notes, and design proposals
- `design-proposals/` — formal design or architecture proposals
- `test-results/` — prompt evaluations, retrieval comparisons, and result notes

Each submission should be placed under a GitHub username and a timestamp, for example:

```text
community/ideas/your-github-username/2026-08-30T090000Z/idea.md
community/test-results/your-github-username/2026-08-30T090000Z/result.md
community/design-proposals/your-github-username/2026-08-30T090000Z/proposal.md
```

The file itself should be a plain Markdown document. Keep it readable and evidence-based. Include the prompt, context, claims, and any sources or URLs that support the result.

The repository may validate these paths in CI to ensure the naming conventions are consistent.
