# Evaluation records

Use this directory to compare the same prompts in Claude Desktop with the
Ganjoor MCP server disabled and enabled.

1. Copy the prompt from `TEST_PROMPTS.md` into both transcript files.
2. Paste Claude's complete response into the matching file.
3. Record whether Claude used an MCP tool and which tools it called.
4. After both runs, fill in `comparison.md`.

Keep the prompt, model/client details, and response settings consistent between
runs. Do not edit Claude's response when pasting it; add observations in the
metadata or comparison file instead.

Record the run time in ISO 8601 format, including the timezone, for example
`2026-08-25T19:45:00-04:00`.
